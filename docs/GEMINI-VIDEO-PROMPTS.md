# 🎬 Gemini Pro Video Generation - Complete Moodboard

## Overview
Generate 6 short dental scan guide videos using Gemini Pro (or similar AI video generation).

**Common Settings for All Videos:**
- Duration: 6-8 seconds
- Resolution: 1080x1080 (square) or 720x1280 (portrait)
- Style: Professional, medical, clean
- Background: Solid white or light gradient
- Lighting: Bright, even, medical-grade
- Subject: Adult (25-35 years), neutral expression initially

## 💡 Gemini Pro Generation Tips

### For Best Results:

1. **Generate in order** (1-6) for consistency
2. **Use same base prompt** elements for all
3. **Specify "continue with same subject"** for videos 2-6
4. **Request multiple variations** if first attempt isn't perfect
5. **Check teeth visibility** in each frame before accepting

### Common Issues to Avoid:

❌ **Subject changes between videos** - Request same person
❌ **Teeth not visible** - Emphasize "teeth clearly visible"
❌ **Too fast movement** - Specify "smooth, gradual movement"
❌ **Wrong angles** - Be explicit about head turn direction
❌ **Poor lighting** - Request "bright medical lighting"
❌ **Jerky motion** - Ask for "smooth natural movement"

### Refinement Prompts:

If video isn't perfect, try:
```
"Make teeth MORE visible"
"Slow down the movement speed"
"Increase lighting brightness"
"Make smile more natural (less forced)"
"Hold final position longer (steady)"
"Zoom in closer on teeth area"
```
